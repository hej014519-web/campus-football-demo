# StartLine 篮球赛事系统测试版

访问地址：https://hej014519-web.github.io/campus-football-demo/basketball/

独立静态 HTML/CSS/JavaScript 测试网站，无构建依赖、外部字体或 CDN。GitHub Pages 发布源为 main 分支根目录；提交本目录的改动后自动更新。PDF 设计文档单独提供。

此版为前端交互演示：示例球队、人员及比分均为虚构；计分、审核、排程在当前页面内模拟，不提供跨设备共享数据库。请勿输入真实个人敏感资料。

目录迁移时保留 index.html 即可。后续可迁移至 startline123.com 或其子域名。
