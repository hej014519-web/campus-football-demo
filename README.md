# 校园足球 · 四身份功能演示站

这是独立的 GitHub Pages 静态演示版，不连接原来的 Sites 生产项目。

- 观众可直接浏览，也可选择观众身份登录工作台。
- 四种身份：观众、选手 / 球队、裁判、赛务。
- 所有身份统一演示账号：**何珈俊**；密码：**123456**。
- 账号口令公开写在客户端，仅用于演示入口，不提供安全认证。
- 仅使用虚构球队、人员及比赛；不要输入真实姓名、身份证、电话、学籍或健康材料。
- 填报、材料标记、审核、比分及公告只在当前页面内模拟。刷新、关闭或重新打开页面后恢复初始示例。
- 材料按钮不会选择或读取实际文件。没有数据库、真实后台请求、浏览器持久存储或跟踪脚本。

## 直接发布

把根目录的 `index.html`、`favicon.svg`、`.nojekyll` 放到 GitHub Pages 发布目录。应用脚本和样式已内嵌在 `index.html`，无需 CDN，不需要服务器安装软件。保留相对路径，适用于 `https://用户名.github.io/仓库名/`。

GitHub 仓库设置：`Settings → Pages → Build and deployment → Deploy from a branch`，选择 `main` 分支与 `/ (root)`，保存后等待 Pages 发布。

不同浏览器或不同人的操作互不共享。

也可直接双击 `index.html` 查看。微信内若出现访问或下载限制，使用右上角菜单在浏览器打开；本项目无法保证或绕过微信的平台策略。

## 从源码重新生成

安装 Node.js 22.13 或更高版本（本次构建使用 Node 24）。在此目录执行：

```sh
npm ci
npm run build
npm test
```

`src/portal.tsx` 为界面，`src/lib/demo.ts` 为纯内存演示状态和统一口令，`src/lib/events.ts` 为赛事参考信息，`src/styles.css` 为全部样式。`scripts/build.mjs` 生成根目录 `index.html`。

## 体验协作流程

1. 登录选手，打开示例队伍，勾选“仅使用虚构资料”，演示提交名单。
2. 退出并登录赛务，查看同一页面中的示例报名并演示审核。
3. 退出并登录裁判，填写示例比赛报告；再切换赛务发布成绩。
4. 返回观众工作台或赛程页查看本页模拟结果。刷新后所有操作重置。

原赛事名称、日期及规程摘要仅供界面演示参考，不代表本网站获得主办方授权或开放真实报名。公开示例赛程、队伍、人员和成绩均为虚构。
